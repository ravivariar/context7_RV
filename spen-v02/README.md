# S Pen Playback MVP 0.2

Adds persistent multi-page handwriting to the original MVP.

- S Pen-only canvas input
- pressure-sensitive strokes
- historical MotionEvent samples
- per-page handwriting timeline and playback resume position
- previous/next page navigation
- add page after current page
- delete page with confirmation
- automatic persistence after edits and page changes
- migration from the original single-page SharedPreferences note when available
- undo, clear, eraser, seek, and 0.5x/1x/2x/4x playback
